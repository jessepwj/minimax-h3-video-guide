# MiniMax H3 视频生成：上手、提示词、模板、做长视频

用 MiniMax 的 H3 模型生成视频（文字、图片、参考素材都能进，成片自带声音和中文对白）。这个仓库把官方文档和公开教程整理成能直接照着做的东西，并附上两个可运行的脚本：一条条生成、再拼成长片。

内容是 2026-10 的实测和整理：脚本里查额度、单条生成、首帧续拍、分镜表批量生成加拼接都真跑过；参考图、参考视频、参考音频、尾帧这几个参数没测，文档里标了「未测」。教程部分是读过公开资料后用自己的话归纳的，每条都附原文链接（见 [docs/06-资料来源.md](docs/06-资料来源.md)）。

## 三十秒上手

1. 拿到订阅 key（以 `sk-cp-` 开头），放进环境变量，不要写进文件、不要发给别人：
   ```bash
   export MINIMAX_API_KEY="你的key"
   ```
2. 查还剩多少额度：
   ```bash
   python3 scripts/h3.py quota
   ```
3. 生成一条 5 秒竖屏（最便宜的档位）：
   ```bash
   python3 scripts/h3.py gen --prompt "清晨的书桌上，一杯热咖啡冒着热气，窗外的阳光缓缓移过桌面，镜头缓慢推近 [push in]" --duration 5 --resolution 480P --ratio 9:16
   ```
   成片在 `out/` 里。要看这条用了多少额度，加 `--measure`。

用 Codex / Claude Code 的话，不用自己敲命令：把 `skills/minimax-h3-video/` 整个文件夹放进 `~/.codex/skills/`（或 `~/.claude/skills/`），然后直接说「帮我用 H3 做一条 15 秒的竖屏视频，内容是……」，它会按 [SKILL.md](skills/minimax-h3-video/SKILL.md) 的流程做。

## 先看这张：额度怎么算

套餐里文本、图像、语音、视频共用一份额度，**视频只扣「周额度」**（一周从首次使用起算 7 天，用不完不结转），不占 5 小时那个窗口。用量接口只给整数百分比，且统计滞后约 20 秒。

实测折算：**100% 周额度 ≈ 110 元的按量价**。每秒视频大约吃掉：

| 档位 | 每秒约占周额度 | 5 分钟约占 | 说明 |
|---|---|---|---|
| H3-Max-Turbo 480P | 0.12%–0.15% | 36%–46% | 实测。最便宜，生成最快（15 秒的片子不到 11 秒出），画质够用 |
| H3-Max 480P | 0.30% | 90% | 实测 |
| H3 / H3-Max 768P | 0.45% | 136% | 实测。画质最好，生成慢（10 秒约 3 分钟） |
| H3-Max-Turbo 768P | 0.24% | 71% | 按价目折算，未测 |
| H3 2K | 0.73% | 218% | 按价目折算，未测 |

结论：**长片用 Turbo 480P 出整条草稿，满意了再挑关键镜头升档。** 详细在 [docs/05-额度与价格.md](docs/05-额度与价格.md)。

## 注意

- **key 不要进仓库、不要截图外发。** 订阅 key 只扣套餐额度，不扣账户余额；但谁拿到谁就能用你的额度。
- **画面里的汉字会糊成乱码**（招牌、屏幕界面），需要字的地方后期叠字幕或图卡。
- 生成的内容要自己检查：人物是否前后一致、有没有多手指之类的瑕疵、台词是否念对。
- 资料来自公开网页，版权归原作者；这里只做归纳并附链接。
