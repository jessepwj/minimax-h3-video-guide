# MiniMax H3 视频生成

仓库根目录有完整的文档和脚本；这里只写做事的顺序。key 在环境变量 `MINIMAX_API_KEY`（订阅 key，`sk-cp-` 开头）。**不要把 key 写进任何文件、提交记录或回复里；缺 key 就让用户自己设置，不要去别处翻。**

## 流程

1. **先问清三件事**：成片多长、讲什么（要不要人物对白）、竖屏还是横屏。含糊就先给一个假设说清楚再做，不要空等。
2. **查额度并估算**：`python3 scripts/h3.py quota`，看 `weekly`（视频只扣周额度）。每秒占用见 `docs/05-额度与价格.md`；Turbo 480P 约 0.12%–0.15%/秒，H3 768P 约 0.45%/秒。**预计会用掉超过一半剩余额度，先告诉用户并等确认。**
3. **默认用最便宜的档**：`MiniMax-H3-Max-Turbo`、480P。用户明确要成片画质再换 `MiniMax-H3` 768P。
4. **一条以内**（≤15 秒）：照 `docs/03-模板库.md` 选模板，`python3 scripts/h3.py gen --prompt "..." --duration N --resolution 480P --ratio 9:16`。
5. **更长**：写分镜表 JSON（格式见 `docs/04-做长视频.md`），先 `python3 scripts/storyboard.py 表.json --dry-run` 看预计占用，再去掉 `--dry-run` 真跑。同一场景用 `"chain": true` 续拍，换场景用参考图锁人物。
6. **提示词**：按 `docs/02-提示词写法.md`。要点：一个镜头一种运镜；时间分段写 `0-5秒：……`；台词放引号里，一次只一个人说；声音单独写一行；不要让模型写汉字，需要字后期叠。
7. **交付前自己检查**：抽几帧看人物是否一致、画面有无瑕疵；有对白的片子用语音识别回读台词是否对；确认总时长、分辨率、画幅符合要求。说清用了多少额度（前后各读一次 `quota`，等 30 秒让统计更新）。

## 边界

- 视频额度花完就停，不要换用别的 key 继续生成（尤其按量付费 key，会扣真钱）。
- 不生成涉及真人肖像冒用、敏感内容的视频；命中 422 就改提示词，不要反复硬试。
- 生成的素材先给用户看，用户确认后再用于发布。
