# 03 模板库

每个模板里 `【】` 是要你填的地方。标「实测」的是我真生成过、检查过结果的原句，其余是按 [02 的规则](02-提示词写法.md)和公开示例组合的写法，没逐条测。时长、分辨率、画幅请写在命令参数里，不要只写在提示词里。

---

## T1 文生·单镜头（物、风景、产品）

```
【主体】在【场景】里，【缓慢的动作】，【光线/时间】，镜头【一种运镜】 [【镜头词】]。声音：【环境声】。
```

实测（H3 768P，4 秒，9:16）：
```
清晨的书桌上，一杯热咖啡冒着热气，窗外的阳光缓缓移过桌面，镜头缓慢推近 [push in]
```
结果：热气、光影移动都对，自带环境音。

## T2 文生·多镜头（时间分段）

```
竖屏，【总秒数】秒。【场景和人物一句话】。
0-5秒：【景别】，【运镜】，【动作】。
5-10秒：切到【另一景别/对象】，【运镜】，【动作】。
10-15秒：回到【景别】，【动作】。
声音：【人声/环境声/音效，各自出现的时间】。一个镜头只做一件事，不要多余字幕。
```

## T3 口播对白（实测）

Turbo 480P，15 秒，9:16。中文台词一字不差，三镜头切得准：
```
竖屏，15秒。一个短发年轻女生坐在明亮的现代办公室里，对着镜头讲话。0-5秒：中近景，固定机位，她微笑着说：“做数据分析，现在对着电脑说话就行。”5-10秒：切到电脑屏幕特写，屏幕上一张柱状图的柱子一根根升起，镜头缓慢推近 [push in]。10-15秒：回到她的中近景，她点点头说：“结果几秒钟就出来了。”声音：她的人声清晰自然，背景有轻微的键盘声。同一时间只有她一个人说话，口型和台词对齐。
```
要点：每段台词一句、一个人说；台词用引号；声音单独一行。每条片子的人声音色是独立生成的，长片里可能漂，见 [04](04-做长视频.md)。

## T4 图生·首帧（只写变化）

命令：`--first-frame 图片`。提示词只写会动的东西，不重复图里已有的外观：
```
【主体】【动作】，【环境里什么在动】，镜头【一种运镜】。保持画面其余部分不变。
```

## T5 续拍（实测）

把上一条的末帧当下一条的首帧（`storyboard.py` 里写 `"chain": true`，或自己用 ffmpeg 抽末帧）：
```
接上一个镜头，保持同一个女生、同样的服装和办公室，她转头看向屏幕，伸手点了一下鼠标，说：“再换个角度看看。”固定机位，不切镜头。
```
结果：人物、服装、办公室与上一条一致，动作按提示词接上。

## T6 首尾帧过渡

命令：`--first-frame A.jpg --last-frame B.jpg`。两张图越接近越平滑：
```
从【A 状态】过渡到【B 状态】，【情绪或动作变化一句话】，镜头【一种运镜】。
```
（未测。两张图只是场景参考，不是像素级的首尾约束。）

## T7 参考生成·锁人物（未测完整流程）

命令：`--ref-image 人物.png --ref-image 场景.png`：
```
图1作为人物的外观参考，图2作为场景参考。保持人物的脸、发型、服装、体型比例不变，不要从图2迁移任何面部特征。
【时间段分镜】
```
每次都用同一张人物图；一张图只管一件事。

## T8 参考生成·借动作或运镜（未测）

命令：`--ref-image 人物.png --ref-video 动作.mp4`：
```
人物参考图1的外观，动作严格参考视频1，【表演内容】。不改变人物服装。
```
视频每段 2–15 秒，合计不超过 15 秒。

## T9 屏幕图表演示（实测）

用来讲数据分析、软件演示的一个镜头：
```
切到电脑屏幕特写，屏幕上一张柱状图的柱子一根根升起，镜头缓慢推近 [push in]。声音：轻微的鼠标点击声和键盘声，不要人声。
```
注意：屏幕上的汉字（坐标轴、标题）会糊，真实的界面和数字请后期用截图或图卡叠上去。

## T10 手机随拍感（UGC，未测）

```
手机单手拍摄的质感：轻微手抖、近距离对焦的犹豫、逆光时曝光有起伏，不要电影感。【场景和人物动作】。声音：【环境声】，人声自然口语化。
```

## 官方和公开示例里常见的套路（供改写）

- **短剧预告（官方，9:16、15 秒）**：先说规格和平台风格，再说人物关系和结局动作，一张图定人物外观、一张图定场景，限定中近景和特写，写明「保持身份一致」。
- **产品广告**：分四段（微距 → 旋转 → 拆解 → 回归定格），结尾写「无手、无变形、无文字」。
- **时装/眼镜广告（官方）**：极简白棚、无缝白背景，图1定人物、图2补面部细节、图3定产品形态。
- **角色登场**：靴子 → 背影/侧身 → 面部特写 → 全身定格，第三段只留一个标志性小动作。
